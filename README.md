# 优选AI

一个输入框，同时问 Claude / ChatGPT / Gemini 网页版（用你自己的会员登录，不走 API），回答并排显示，还可以让其中一个 AI 当裁判对比总结。

## 安装
1. 打开 `chrome://extensions`，右上角打开「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本文件夹 `D:\claudecode\优选AI`。
3. 把插件固定到工具栏（拼图图标 → 图钉）。
4. 先在 Chrome 里分别登录 claude.ai、chatgpt.com、gemini.google.com。

## 使用
1. 点插件图标，打开「优选AI」对比页。
2. 勾选要问的 AI（Gemini 默认不勾，勾选状态会记住），输入问题，点「同时提问」或按 Ctrl+Enter。
3. 插件会在后台标签页（标签组「AI对比」）里新开对话并发送，回答实时显示在对比页里。
   想在原网页继续追问，点面板上的「打开原网页」。
4. 所有回答完成后，底部出现「让 AI 对比这些回答」：选一个裁判，插件会把回答匿名成 A/B/C 发给它，结论显示在最下方，并标注 A/B/C 各是谁。
   也可以直接点 Chrome 右上角的「问问 Gemini」，让它读当前对比页来总结。

每次新提问会复用同一组标签页（跳到新对话），不会越开越多。

### 选择模式、模型和思考强度
点「刷新模型列表」，插件会打开各网站的模型菜单，读出你账号当前可用的选项，填进每个网站旁边的下拉框。选择会被记住；选「默认」就不切换。

| 网站 | 模式 | 模型 | 思考强度 |
| --- | --- | --- | --- |
| ChatGPT | 聊天 / 工作（两种模式各有一套模型和强度） | 模型菜单里的列表 | 模型菜单里的强度滑块 |
| Claude | — | 含「更多模型」子菜单 | 「努力程度」子菜单 |
| Gemini | — | 模式菜单上半部分 | 模式菜单下半部分（低点/中等/高点） |

提问时插件按 模式 → 模型 → 强度 的顺序在网页上切换后再发送，面板标题会显示实际使用的设置；切换失败会黄字提示，并继续用网站当前设置回答。
ChatGPT 的强度档位随模型变化，下拉框里列的是刷新时所选模型的档位。读取时会临时拨动滑块、切换模式，读完自动恢复原样。

## 出问题时
失败的面板下方有可折叠的「诊断信息」，点「复制诊断信息」发给开发者即可定位问题。
网站改版后最常见的问题是“找不到输入框 / 没检测到回答”。所有页面元素的选择器都在 `sites.js` 里，每项有多个备选，按顺序尝试；改完后在 `chrome://extensions` 点插件的刷新按钮即可。

| 文件 | 作用 |
| --- | --- |
| `sites.js` | 各站点网址和页面元素选择器 |
| `content/runner.js` | 注入到 AI 网站：填问题、点发送、抓回答 |
| `lib/sanitize.js` | 清洗回答 HTML、转 Markdown |
| `compare.html/.js/.css` | 对比页 |
| `background.js` | 点图标打开对比页 |

说明：这是自用、手动触发、低频的自动化；遇到人机验证需要你自己在原网页完成。
